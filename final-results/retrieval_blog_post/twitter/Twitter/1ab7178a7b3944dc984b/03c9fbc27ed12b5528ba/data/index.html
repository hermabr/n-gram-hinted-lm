I build a hint corpus of the tokens that follow each n-gram in the training data. The model receives these tokens as hints and learns how to use them.
Herman Brunborg@hermanbrunborg·1m
Scaling the hint corpus has accelerating returns. On a fixed model checkpoint, each doubling cuts the loss more than the last. I build the hint corpus in the timed run, so a faster builder means a larger corpus.
Herman Brunborg@hermanbrunborg·1m
The CPUs used to be idle, so I build the corpus on them, in parallel with model training on the GPUs. My builder is branch-free SIMD code that fits in L2 cache and uses a custom data structure. It is 500x faster than Python and 11x faster than the best auto-researched Rust code.
